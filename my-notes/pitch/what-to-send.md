# What To Send (So Investors Actually Read It)

## Default outbound (cold email)

- Send: `preseed-deck-recommended.md` exported to PDF (10-12 slides).
- Optional: 1-page memo only if requested.

## Before first call

- Send the same deck PDF again (don’t add more docs).

## After first call (if there is interest)

- Share additional material selectively:
  - `pitch/pitch-deck-500k-preseed.md` (speaker notes / longer copy)
  - `pitch/investor-qa.md`
  - `pitch/demo-script.md`
  - `pitch/competitive-landscape.md`
  - `pitch/risks.md`

Rule: if you attach more than one document on first touch, most people read none.
