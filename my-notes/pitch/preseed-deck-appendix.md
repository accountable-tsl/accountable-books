# Accountable Books

## Pre-Seed Deck Appendix (Optional Slides)

Use these only if an investor asks, or as backup slides.

---

## A1. Vision (Ledger-First Trajectory)

Wedge now:

- Firm-first bookkeeping and close workbench with explainable automation.

Becomes:

- Event -> policy -> ledger -> reports, with provenance and continuous controls.
- Expand into independent truth domains: payroll, compliance, payables, revenue, assets.
- Long-term: network-native financial events (less re-keying, fewer reconciliations).

---

## A2. Competitive Matrix (2x2 Suggestion)

Axes:

- Firm-first vs SMB-direct
- Explainable/audit-safe vs opaque automation

Placeholders:

- Firm-first + explainable: Accountable Books (and closest adjacent players)
- SMB-direct + explainable: [where Digits-like products sit]
- SMB-direct + legacy: QBO/Xero ecosystem
- Workflow-only: practice management tools

---

## A3. Metrics to Instrument Early

Operational:

- Close readiness: % periods “ready”, time-to-ready.
- Exceptions aging: unresolved count, needs-review count, SLA by firm.
- Throughput: transactions reviewed per bookkeeper per hour/day.

ML:

- Suggestion acceptance rate.
- Precision at confidence thresholds.
- Coverage: % autoposted vs % requiring review.

---

## A4. Risk Register (Tight)

- Reporting UI gap (TB/P&L/BS): ship close hub first, then financials.
- ML claims: treat accuracy as target until evaluation harness exists.
- Multi-tenant authorization: standardize middleware enforcement + add tests.
- Split-market focus: Nigeria-first pilots; US-ready, not simultaneous push.
