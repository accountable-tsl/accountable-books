# Visuals Checklist (Make The Deck Skimmable)

Goal: every slide should have one visual anchor. Avoid text-only slides.

## Screenshots to capture (from the live app)

- Categorization queue view: unresolved / candidate / posted (show confidence + reason if visible).
- Single transaction detail: edit -> confirm -> posted (show audit-safe behavior).
- Journals list + journal detail pane (double-entry lines visible).
- Bank accounts: connected accounts + last sync status.
- Firm context / company switcher (multi-tenant feel).

## Simple diagrams to draw (in Slides/Figma)

- 4-step pipeline: Ingest -> Classify -> Review -> Post.
- Flywheel loop: corrections -> labels -> better suggestions -> less review.
- Competitive 2x2: Firm-first vs SMB-direct, Explainable vs Opaque.
- Roadmap timeline: now -> close loop shipped -> design partners -> seed-ready.

## Design rules (practical)

- One headline per slide (<= 7 words).
- <= 3 bullets per slide, <= 7 words per bullet (except the Product screenshot slide).
- Big typography: 32-44pt headline, 20-28pt body.
- Use icons sparingly; prefer screenshots and simple shapes.
