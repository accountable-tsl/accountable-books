Engine design for speed (and simplicity)
- Single fetch per run: load all enabled rules for the company’s applicable tiers in one query.
- Pre-filter by cheap fields first (direction, bank_scope, tier) before evaluating the condition tree.
- Precompile condition trees to JS functions once (memoized) and reuse.
- Short-circuit: stop evaluating a rule as soon as a group fails.
- Apply in-memory, batch logs (buffer then insert), avoid DB roundtrips per rule.
- No regex on tenant rules; only allow in system rules (and cache compiled patterns).
- Use cache wisely

Execution Flow
- Categorization job is enqueued in rule-runner.queue file
- Worker in rule-runner.worker file picks up that job and executes runRulesForEnrichedTransaction which sits in rule-runner.service file
- The runRulesForEnrichedTransaction does the following:
    - Reorganizes the input for the rules engine, runs the rule engine, and persist the results by adding metadata to categorization task and create prediction + candidate records
- The rulesEngine.run function executes:
    - It fetches the applicable rules via RuleRepository.fetchApplicableRules
    - For each rule, in a deterministic order, it compiles conditions and actions using RuleCompiler (cached fingerpint)
    - Evaluate the rules in priority order
    - Execute the matching Rules
    - Detect conflicts, if any
    - Persist logs  



----

File Structure

- rules.def.* - Rule JSON schema (conditions, actions, templates)
- rules.types.ts - Shared TypeScript types (RuleEntity, RuleDraftState, etc.)
- rules.compiler.ts - Compiles rule JSON → executable functions (CompiledCondition, CompiledAction)
- rules.engine.ts - Pure engine: runs compiled rules against transaction, returns RuleEngineResult
- rules.repository.ts - DB access: fetches applicable rules by scope/priority
- rule-logs.* - Persists execution logs (RuleLogDraft → DB) for audit/debugging
- rule-runner.* - Job orchestration: event → engine → persist outcome → create predictions
- rules.txt - Design notes and architecture decisions
