# Accountable App

## Overview

**Accountable App** is the frontend part of a dual-component financial management system designed to help individuals and small to medium-sized businesses manage their financial records more efficiently. The app interfaces with the `accountable-api` to provide a responsive and intuitive user experience.

## Technology Stack

- **Frontend**: React, Typescript, SASS, Tailwind CSS

## Getting Started

### Prerequisites

- Node.js

### Installation

Follow these steps to set up the project locally:

1. **Clone the Repository**

```
git clone git@github.com:accountable-tsl/accountable-app.git
```

2. **Navigate to the project directory**

```
cd accountable-app
```

3. **Install Dependencies**

```
npm install
```

4. **Run the Development Server**

```
npm run dev
```

## MVP Features

- **Dashboard**: Overview of financial data.
- **Chart of Accounts**: Manage and review accounts.
- **Transaction Management**: View and categorize financial transactions.
