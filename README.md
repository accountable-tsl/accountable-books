# Accountable Books Monorepo

Monorepo for the **Accountable Books** project, managed with [pnpm workspaces](https://pnpm.io/workspaces) and [Turborepo](https://turbo.build/).

## Status

This repo currently contains the **skeleton only** (workspace + Turbo config)

## Structure (planned)

- `apps/` — application code (to be added)
  - `api` — Node/Express backend
  - `web` — React/Vite frontend
  - `ml-engine` — Python service
- `packages/` — shared code (to be added)

## Prerequisites

- Node.js **>= 18**
- pnpm **>= 8**

## Setup

```sh
pnpm install
```
